# Инструкция для пользователя

Этот документ помогает быстро и правильно использовать AI-агента `consulting_agent.py` для задач финансового консалтинга.

## 1) Что делает агент

Агент автоматизирует цикл работы с клиентом:

- Лид и квалификация
- Выбор услуги под задачу
- Анализ данных клиента
- Формирование структурированного отчёта в Markdown
- Сохранение отчётов в `reports/`

Агент работает через CLI и использует методологии из папки `skills/`.

## 2) Для каких задач подходит

Агент полезен, когда нужно:

- быстро сделать первичную диагностику бизнеса;
- рассчитать и сравнить сценарии по НДС;
- подготовить структуру управленческого учёта;
- получить проектный план по финансовой модели;
- оценить законные варианты налоговой оптимизации;
- сформировать материалы для CFO-light сопровождения;
- квалифицировать лид и подготовить основу КП.

## 3) Какие услуги доступны и когда их применять

Коды услуг используются в параметре `--service`.

- `1` Финансовая диагностика  
  Когда: нужен общий health-check бизнеса, поиск потерь и рисков.
- `2` НДС-аудит и сопровождение  
  Когда: требуется выбор сценария НДС (с 2026: 22% / 5% / 7%), расчёт нагрузки и дорожная карта.
- `3` Управленческий учёт  
  Когда: нужно внедрить/упорядочить P&L, ДДС, KPI, регламент данных.
- `4` Финансовая модель  
  Когда: нужен прогноз, сценарии, точка безубыточности, инвестиционная логика.
- `5` Налоговая оптимизация  
  Когда: требуется легальное снижение налоговой нагрузки и приоритизация мер.
- `6` CFO-light  
  Когда: нужен формат регулярного внешнего финансового директора.
- `7` Квалификация лида + КП  
  Когда: нужно оценить лид и сформировать персонализированное предложение.
- `8` Полный цикл  
  Когда: нужна комплексная проработка (диагностика -> КП -> проектный план).

## 4) Поддерживаемые входные форматы

Агент принимает данные клиента из:

- `.xlsx`, `.xls`
- `.csv`
- `.json`
- `.txt`, `.md`

Рекомендуемые файлы:

- `data/clients/template_client.md` — шаблон карточки клиента;
- `data/clients/test_client.md` — пример заполнения.

## 5) Требования перед запуском

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Создать рабочий `.env`:

```bash
cp .env.example .env
```

3. Заполнить минимум:

- `ANTHROPIC_API_KEY`
- при необходимости модель (`DEFAULT_MODEL`, `FALLBACK_MODEL`)
- данные консультанта (`CONSULTANT_NAME`, `CONSULTANT_PHONE`)

## 6) Основные команды

### Интерактивный режим

Когда нужен пошаговый ввод (файл, услуга, контекст):

```bash
python consulting_agent.py analyze
```

### Неинтерактивный запуск (рекомендуется для стандартизированной работы)

Когда хотите воспроизводимый сценарий:

```bash
python consulting_agent.py analyze --file data/clients/test_client.md --service 2 --name "ООО ТД Центр" --no-interactive
```

### Добавить контекст консультанта

Когда нужно уточнить бизнес-ситуацию, ограничения, дедлайны:

```bash
python consulting_agent.py analyze --file data/clients/client.md --service 1 --name "ООО Клиент" --context "Кассовые разрывы и рост дебиторки с Q3" --no-interactive
```

### Список сохранённых отчётов

```bash
python consulting_agent.py list-reports
```

## 7) Как правильно готовить данные

Чтобы отчёт был полезным и точным:

- давайте цифры минимум за `2024`, `2025`, `2026 (факт/прогноз)`;
- добавляйте структуру выручки, себестоимости, расходов;
- по НДС фиксируйте долю поставщиков/покупателей-плательщиков;
- описывайте боли клиента его языком;
- отмечайте ограничения: сроки, лимиты, регуляторные риски.

## 8) Что пользователь получает на выходе

Результат:

- Markdown-отчёт в терминале;
- файл отчёта в `reports/` с отметкой времени;
- структурированные выводы, риски (`🔴`, `🟡`, `🟢`), рекомендации и блок "Следующий шаг".

## 9) Практический сценарий использования (рекомендуемый)

1. Заполните `template_client.md` под клиента.
2. Запустите `service 1` (диагностика) для первичной картины.
3. Запустите профильную услугу (`2`, `3`, `4`, `5` или `6`) для детального решения.
4. Запустите `service 7` для формализации предложения и КП.
5. При необходимости запустите `service 8` для комплексного плана.

## 10) Как интерпретировать отчёт

- Сначала смотрите `Executive/итоговые выводы`.
- Затем — таблицы с цифрами и сценариями.
- Отдельно анализируйте блок рисков (`🔴` приоритет 1).
- Внедряйте рекомендации по приоритету: высокий -> средний -> низкий.
- Фиксируйте следующий шаг с дедлайном и ответственным.

## 11) Частые ошибки и что делать

- **Ошибка `ANTHROPIC_API_KEY не задан`**  
  Проверьте файл `.env` и корректность ключа.
- **Ошибка модели (`not_found` / `forbidden`)**  
  Проверьте `DEFAULT_MODEL` и права ключа в аккаунте Anthropic.
- **Пустой или слабый отчёт**  
  Добавьте более полные входные данные и контекст в `--context`.
- **Некорректные суммы**  
  Уточните исходный файл (формат колонок, единицы измерения, пропуски).

## 12) Границы ответственности

Агент формирует аналитические рекомендации на основе предоставленных данных.
Юридически значимые решения, налоговые позиции и финальные расчёты нужно подтверждать у профильного эксперта на основании первичных документов.
